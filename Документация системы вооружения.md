# Техническая документация системы вооружения в Crysis Wars

## Обзор

Данная документация описывает архитектуру и реализацию системы вооружения в игре Crysis Wars, с особым вниманием к сетевому взаимодействию между клиентом и сервером. Система разработана для обеспечения синхронизации действий игроков в многопользовательской игре, управления стрельбой, перезарядкой, прицеливанием и другими функциями оружия.

## Архитектура системы

Система вооружения в Crysis Wars построена на базе классов `CWeapon` и его дочерних классов, реализующих различные типы оружия. Файл `WeaponClientServer.cpp` содержит реализацию сетевого взаимодействия для этих классов, обеспечивая:

- Синхронизацию состояния оружия между клиентами
- Передачу команд от клиента к серверу
- Трансляцию действий игрока всем остальным клиентам
- Проверку валидности запросов от клиентов
- Обработку различных действий с оружием (стрельба, перезарядка, прицеливание и т.д.)

## Сетевая модель

Система использует клиент-серверную архитектуру с сервером в качестве авторитетного источника:

1. **Клиент** - отправляет запросы на действия с оружием серверу
2. **Сервер** - проверяет валидность запросов, обрабатывает их и рассылает обновления всем клиентам
3. **Удалённые клиенты** - получают уведомления о действиях других игроков и обновляют состояние игрового мира

## RMI (Remote Method Invocation)

Система использует механизм RMI (удалённый вызов методов) для сетевого взаимодействия. RMI делятся на две основные категории:

### 1. Клиентские RMI (Cl*)

Вызываются сервером на клиентах для уведомления о событиях:
- `ClShoot` - уведомление о выстреле
- `ClStartFire` - начало стрельбы
- `ClStopFire` - окончание стрельбы
- `ClReload` - перезарядка оружия
- `ClZoom` - изменение увеличения (прицеливание)
- `ClMeleeAttack` - ближняя атака
- `ClLock` - блокировка цели
- `ClUnlock` - разблокировка цели
- `ClWeaponRaised` - поднятие/опускание оружия
- `ClStartSecondaryFire` - начало вторичного огня
- `ClEndReload` - завершение перезарядки
- `ClCancelReload` - отмена перезарядки
- `ClStartMeleeAttack` - начало ближней атаки

### 2. Серверные RMI (Sv*)

Вызываются клиентами на сервере для запроса действий:
- `SvRequestShoot` - запрос на выстрел
- `SvRequestShootEx` - расширенный запрос на выстрел
- `SvRequestStartFire` - запрос на начало стрельбы
- `SvRequestStopFire` - запрос на окончание стрельбы
- `SvRequestReload` - запрос на перезарядку
- `SvRequestZoom` - запрос на прицеливание
- `SvRequestFireMode` - запрос на изменение режима стрельбы
- `SvRequestMeleeAttack` - запрос на ближнюю атаку
- `SvRequestLock` - запрос на блокировку цели
- `SvRequestUnlock` - запрос на разблокировку цели
- `SvRequestWeaponRaised` - запрос на поднятие/опускание оружия
- `SvRequestStartMeleeAttack` - запрос на начало ближней атаки
- `SvRequestStartSecondaryFire` - запрос на начало вторичного огня
- `SvRequestCancelReload` - запрос на отмену перезарядки

## Потоки данных

Стандартный поток данных при выполнении действия с оружием:

1. **Клиент** -> Запрос к серверу (SvRequest*)
2. **Сервер** -> Проверка валидности запроса
3. **Сервер** -> Выполнение действия на сервере (Net*)
4. **Сервер** -> Рассылка уведомлений всем клиентам (Cl*)
5. **Клиенты** -> Выполнение соответствующего действия (Net*)

## Типы запросов

### Стрельба (Shoot)

```
Клиент -> SvRequestShoot/SvRequestShootEx -> Сервер
Сервер -> ClShoot -> Все клиенты
```

### Начало/окончание стрельбы (StartFire/StopFire)

```
Клиент -> SvRequestStartFire/SvRequestStopFire -> Сервер
Сервер -> ClStartFire/ClStopFire -> Все клиенты
```

### Перезарядка (Reload)

```
Клиент -> SvRequestReload -> Сервер
Сервер -> ClReload -> Все клиенты
```

### Прицеливание (Zoom)

```
Клиент -> SvRequestZoom -> Сервер
Сервер -> ClZoom -> Все клиенты
```

## Обработка действий оружия

### NetShoot / NetShootEx

Функции для выполнения выстрела на сетевом уровне. `NetShootEx` предоставляет расширенные параметры, такие как позиция, направление, скорость и дополнительные данные.

### NetStartFire / NetStopFire

Функции для начала и окончания стрельбы на сетевом уровне.

### NetStartSecondaryFire

Функция для активации вторичного режима стрельбы оружия.

### NetStartMeleeAttack / NetMeleeAttack

Функции для выполнения ближних атак оружием.

### NetZoom

Функция для изменения увеличения (прицеливания).

## Модификации TheOtherSide

Мод "TheOtherSide" вносит ряд изменений в стандартную систему вооружения, в основном направленных на поддержку ИИ в мультиплеерном режиме:

### Основные изменения:

1. **Поддержка ИИ в мультиплеере**:
   - Добавлена проверка `IS_AI_IN_MP(pActor)` для определения ИИ-актеров в мультиплеерной игре
   - Использование `eRMI_ToRemoteClients` для отправки действий ИИ другим клиентам, так как сервер уже выполняет эти действия

2. **Изменения в запросах**:
   - Модификация логики `RequestShoot`, `RequestMeleeAttack`, `RequestStartFire` и других для поддержки ИИ
   - Добавление дополнительных условий для проверки ИИ-актеров

3. **Исправления ошибок**:
   - Фикс для оружия, не выполняющего действия без владельца на удаленном клиенте
   - Исправления в логике проверок здоровья и статуса актеров

## Особенности реализации

### Проверка владельца (CHECK_OWNER_REQUEST)

Макрос `CHECK_OWNER_REQUEST` используется для проверки валидности запросов от клиентов, убеждаясь, что запрос поступил от законного владельца оружия:

```cpp
#define CHECK_OWNER_REQUEST()                                                             \
	{                                                                                     \
		uint16 channelId = m_pGameFramework->GetGameChannelId(pNetChannel);               \
		IActor *pOwnerActor = GetOwnerActor();                                            \
		if (pOwnerActor && pOwnerActor->GetChannelId() != channelId && !IsDemoPlayback()) \
			return true;                                                                  \
	}
```

### Управление боеприпасами

Система отслеживает текущее количество боеприпасов и синхронизирует его между клиентами:

- `NetGetCurrentAmmoCount` - получение текущего количества боеприпасов
- `NetSetCurrentAmmoCount` - установка текущего количества боеприпасов

### Запись игрового процесса

Система также взаимодействует с системой записи игрового процесса для регистрации важных событий:

```cpp
m_pGameplayRecorder->Event(GetOwner(), GameplayEvent(eGE_WeaponMelee, 0, 0, (void *)GetEntityId()));
```

### Валидация выстрелов

Для предотвращения читерства, система включает механизм валидации выстрелов:

```cpp
if (pActor && !isLocal && params.seq)
{
    if (CGameRules *pGameRules = g_pGame->GetGameRules())
        pGameRules->ValidateShot(pActor->GetEntityId(), GetEntityId(), params.seq, params.seqr);
}
```

## Заключение

Система вооружения в Crysis Wars представляет собой сложную клиент-серверную архитектуру, обеспечивающую точную синхронизацию действий игроков в многопользовательской игре. Мод "TheOtherSide" расширяет эту систему, добавляя поддержку ИИ в мультиплеерном режиме и исправляя некоторые проблемы базовой реализации.
